Job Screen Alerts

Job Screen Alerts is a personal job-search assistant. It collects job postings, organizes an Apply today shortlist with MBA internships first, and sends new-match alerts and application reminders to the account owner.

What it does

  • Keeps internship and full-time alerts separate.
  • Reminds the owner at 6 and 18 hours when shortlisted roles still need a decision.
  • Stops or postpones reminders when a job is marked Applied, Pass, or Snooze in the private dashboard.
  • Runs on the owner's server so the laptop can sleep.

Why it requests Gmail access

The app requests Gmail send permission to deliver the owner's requested alerts. It requests Gmail read permission to search Sent for the unique reference of an alert and confirm any matching message before sending, which helps prevent duplicates. Google's read permission technically covers the mailbox, but this application only searches Sent for its own alert references. It also checks the Gmail account address to confirm the intended sender and recipient.

It does not apply to jobs, send messages to employers, or use mailbox content to score jobs. There is no public signup, and this information page does not give access to the private dashboard.

Read the privacy policy for data handling and revocation details, and the terms of use for the intended use of this personal tool. Contact information is shown on Google's consent screen.
